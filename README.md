# 再生設計AI — 閲覧専用プレビュー

築古ビル再生（リノベーション・コンバージョン）の企画・設計・見積もりを支援する
社内向けツールの、**画面と出力例を確認するための静的プレビュー**です。

https://playmark0227-svg.github.io/renovation-feasibility-preview/

## これは何か

既存図面から次の4つを出力するWebアプリケーションの、画面プレビューです。

1. **図面読み取り** — 既存図面から建物・各階の情報を構造化抽出し、人が確認・修正して確定する
2. **法規適合性チェック** — 現行法とのギャップを根拠条文つきで提示（26ルール／12カテゴリ）
3. **工事項目の顕在化と概算コスト** — 過去実績から工事費をレンジで予測
4. **再生プラン提案** — 用途配分・ラウンジ密度を変えたときの収益性を比較

加えて、抽出した数値から**積層ボリュームモデル**を生成します。
階をクリックすると、その階の用途・面積とおおよその工事費が表示されます。
図面を立体復元したものではなく、各階床面積・階高・コア面積から組んだスタッキング模型です。

## プレビュー版の制限

このリポジトリには**ビルド済みの静的HTMLのみ**が含まれます。アプリケーションのソースコードは
含まれていません。次の機能は動作しません。

- 図面のアップロード
- AI（Claude API）による図面読み取り・法規論点の抽出
- データの作成・更新・保存
- 認証

画面上のフィルタ・ソート・タブ・折りたたみ・ラウンジ密度シミュレータの操作は動作します。

## データについて

表示されているデータは**すべて架空**です。物件・実績案件・金額はいずれも実在しません。
概算金額は動作確認のために生成したサンプル値であり、見積もりの根拠には使えません。

## 出力の位置づけ

本ツールの出力は初期検討のための論点整理であり、法適合性を証明するものではありません。
確認申請・行政協議・消防同意の可否は、建築士による現地調査および特定行政庁・消防機関との
協議により最終判断してください。
